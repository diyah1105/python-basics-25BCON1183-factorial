# Factorial Calculator

## Project Description
This project contains a Python program that calculates the factorial of a number entered by the user.

## Features
- Accepts an integer as input.
- Calculates factorial using a `for` loop.
- Displays the result.

## Requirements
- Python 3.x

## Installation
1. Download or clone this repository.
2. Make sure Python 3 is installed.

## Usage
Run the program using:

```bash
python factorial.py
```

Enter a number when prompted.

## Example

**Input:**
```text
Enter a number: 5
```

**Output:**
```text
Factorial of 5 is 120
```
